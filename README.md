## 🚀 Quickstart & Installation

```bash
git clone https://github.com/OrderStream/orderstream-mesh.git
cd orderstream-mesh
pip install -e .
```

```bash
# List all 24 solvers and architecture pillars

# Scan GitHub Actions workflows for context-injection vulnerabilities (Pillar 3.9)
```
